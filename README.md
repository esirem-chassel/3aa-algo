# Algorithmique et Programmation

Ce dépôt liste les différentes activités dans le cadre du module "Algorithmique et Programmation", avec un focus sur le langage C.

Les deux premiers TDs sont à réaliser avant les TPs.
Il est conseillé de conserver les productions de ces TDs, étant donné que les premiers TPs se basent sur vos productions.

L'usage de l'IA dans le cadre du cours est très fortement déconseillée (et interdite évidemment en épreuve).
En effet, une réflexion personnelle et des habitudes personnelles sont nécessaires, faute de quoi aucun apprentissage n'est réalisé.
